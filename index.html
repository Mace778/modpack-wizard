核心能力

整合包管理需要的，这里都有

从新建、添加、维护到打包分发，一条链路在单窗口内完成。

📦

双格式支持

Modrinth 的 modrinth.index.json / .mrpack 与 CurseForge 的 manifest.json / .zip，均可打开、编辑并互相导出。

🔍

Modrinth 搜索添加

粘贴项目链接或 ID，在线获取版本列表，按 MC 版本与加载器筛选，一键加入整合包。

🧩

本地 JAR 智能识别

计算本地文件 SHA1 反查 Modrinth，自动补全项目名称、版本与下载信息，无需手填。

🔗

自动补齐依赖

解析版本依赖关系，列出缺失项并批量安装，已存在的依赖自动跳过。

🧪

批量更新检查

高并发查询每个模组的最新兼容版本，带百分比进度展示，勾选后批量更新。

🩺

兼容性体检

按当前 Minecraft 版本与加载器标记不兼容模组，rp/sp 自动豁免加载器规则。

🔁

重复检测与对比

按项目 ID / SHA1 / 路径找出重复条目；两个整合包之间可做文件级版本差异对比。

⚙️

三种加载器在线版本

Fabric、Forge、NeoForge 的加载器版本均在线拉取；中英双语、明暗主题随心切换。

工作流程

四步完成一个整合包

无论是从零搭建还是维护既有整合包，流程都同样直接。

新建或打开

通过向导创建新整合包，或直接打开本地 .mrpack / .zip。

添加内容

在线搜索、拖入本地 JAR 或 CSV 批量导入，依赖自动补齐。

检查维护

更新检查、兼容性体检、重复检测，让模组列表保持干净可靠。

打包分发

导出 .mrpack / .zip，或一键把全部文件下载到整合包目录。
